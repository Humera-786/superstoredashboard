Retail Sales & Profit Intelligence Dashboard

Project Overview

The Retail Sales & Profit Intelligence Dashboard is a web-based data analytics application designed to analyse Superstore retail transaction data and generate meaningful business insights. The application processes CSV datasets containing sales, profit, quantity, discounts, products, customers, regions, and order dates. It presents the results through interactive dashboards, charts, key performance indicators (KPIs), and summary tables to support data-driven business decisions.

Objectives

- Analyse sales and profit performance.
- Identify top-performing and loss-making products.
- Compare sales across categories and regions.
- Analyse monthly sales and profit trends.
- Investigate the relationship between discounts and profit.
- Identify missing values, duplicate records, and invalid dates.
- Filter and search records and export filtered data.

Key Features

- Interactive sales and profit dashboard.
- KPI cards for total sales, total profit, quantity sold, and orders.
- Category-wise and region-wise performance analysis.
- Top and bottom product performance analysis.
- Monthly sales and profit trend visualisations.
- Discount and profitability analysis.
- Data-quality checks.
- Search, filtering, and CSV export.

Note: These features should be included only if they are implemented in the application.

Dataset

The project uses a Superstore retail sales dataset in CSV format.

Typical columns include:

- Order ID
- Order Date
- Customer Name
- Segment
- Region
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit

The exact columns depend on the uploaded dataset.

How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Run "index.html" using Live Server or the appropriate local server.
4. Upload a supported Superstore CSV dataset.
5. Explore the dashboard and analyse the results.
